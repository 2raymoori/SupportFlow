*SupportFlow*
is a multi-tenant customer support and ticket management platform that enables organizations to efficiently create, assign, track, and resolve support requests. The platform provides role-based access for administrators, managers, support agents, and customers, with features including ticket lifecycle management, team collaboration, comments, file attachments, audit logging, and organization management.
The system is built around a NestJS REST API with a React-based frontend and is designed as a production-oriented application with a strong focus on secure authorization, tenant isolation, scalable backend architecture, testing, and deployment.
